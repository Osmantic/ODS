## What the observations mean

- Repository owner/name identifies the artifact publisher or quantizer repository; it is not a claim about legal ownership. Base models are recorded only when stated in `base_model` or identified in cited card prose. A similar family/name is never substituted.
- License identifiers are publisher declarations for the named model repository. A code license is not automatically a license grant for model weights. Different quantizer, fine-tune and ancestor declarations remain separate; this inventory does not invent an SPDX combination or resolve conflicting claims.
- A **card/API** link supports the observed license declaration. A **terms** link was separately fetched successfully. An absent separate document is distinguished from an absent license declaration. Neither observation establishes compliance with attribution, redistribution, acceptable-use or other conditions.
- Artifact metadata is read at the revision used in the catalog URL. For a mutable `main` URL, the returned commit is recorded below. Base repositories referenced without a commit are independently resolved to their current `main` revision; those are reviewed document revisions, not proof of which exact base weights produced the quantization.
- Hugging Face `gated` is an access-control observation at review time, not a licensing exemption or historical claim. `false` does not establish that no terms or acceptance are required. Public metadata was used when gated raw documents returned HTTP 401; no authentication, acceptance, bypass or private source was used.
- [Hugging Face model-card documentation](https://huggingface.co/docs/hub/model-cards) defines the license and base-model metadata being recorded here. Public endpoints and hashes are retained so another reviewer can reproduce the observations without copying entire agreements into this repository.
