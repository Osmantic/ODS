## How to close a record

For each retained image, record its original source URL, author/rightsholder,
exact license or written permission, attribution text, redistribution scope,
and the reviewed file hash. Retain the grant in an appropriate evidence store;
publish only the portion needed to substantiate permission. A contributor
statement, download page, filename or embedded color profile is not a substitute
for the image rights holder's applicable grant.

If an image is Apple-owned or Apple-licensed, consult
[Apple's copyright guidelines](https://www.apple.com/legal/intellectual-property/guidelinesfor3rdparties.html).
The profile metadata above does not by itself prove that an image is Apple-owned.

The ODS mark (`public/osmantic-isolated-os.png`) and favicon also need a durable
source/authorization record before downstream rebranding or redistribution is
represented as cleared. They are not part of the 12-wallpaper count.

Inter and JetBrains Mono already carry their copyright and SIL OFL 1.1 terms in
[the bundled font notice](../extensions/services/dashboard/public/fonts/OFL.txt).
Keep those notices with the fonts. See
[dashboard asset notices](../extensions/services/dashboard/ASSET-NOTICES.md)
for the Pixel-derived renderer and JavaScript dependency boundaries.
