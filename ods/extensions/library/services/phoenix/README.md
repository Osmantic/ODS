# Phoenix — LLM Observability, Traces, and Evaluation

An optional, lightweight AI observability and evaluation platform by Arize. Phoenix provides an OpenTelemetry-native trace collector, latency breakdown, prompt inspection, and evaluation framework in a single self-contained container without requiring external databases.

## Setup

Set configuration parameters in your ODS `.env` file before enabling **Phoenix (AI Tracing & Evals)**:

- `PHOENIX_SECRET`: session signing secret and API authentication token (auto-generated by `setup.sh`).
- `PHOENIX_PORT`: published Web UI port (defaults to `6006`).
- `PHOENIX_GRPC_PORT`: published OpenTelemetry gRPC collector port (defaults to `4317`).

If absent, running `setup.sh` automatically provisions a secure random 32-character secret into `.env`. Compose refuses missing or empty secrets.

Once enabled:
- **Web UI & Trace Explorer**: `http://localhost:6006`
- **OTLP gRPC Endpoint**: `http://localhost:4317` (or `http://phoenix:4317` within `ods-network`)
- **OTLP HTTP Endpoint**: `http://localhost:6006/v1/traces` (or `http://phoenix:6006/v1/traces`)

## Settings

| Variable | Default | Description |
| --- | --- | --- |
| `PHOENIX_PORT` | `6006` | Published host port for the Phoenix Web UI and HTTP trace ingestion |
| `PHOENIX_GRPC_PORT` | `4317` | Published host port for OpenTelemetry gRPC trace ingestion |
| `PHOENIX_SECRET` | required | Secret signing key for session security and dashboard access |

The default binding is loopback (`127.0.0.1`). Container privilege escalation is restricted via `no-new-privileges:true`.

## Usage & Trace Export

### LlamaIndex Tracing

```python
import phoenix as px
from openinference.instrumentation.llama_index import LlamaIndexInstrumentor

# Point instrumentation to local Phoenix collector
LlamaIndexInstrumentor().instrument(
    tracer_provider=px.register(endpoint="http://localhost:6006/v1/traces")
)
```

### LiteLLM / OpenAI Tracing

Configure OpenTelemetry environment variables in your application:

```bash
export OTEL_EXPORTER_OTLP_ENDPOINT="http://localhost:4317"
export OTEL_EXPORTER_OTLP_PROTOCOL="grpc"
```

## Data and Persistence

Trace spans, evaluations, and datasets persist locally under `./data/phoenix`. Restarting or updating the container retains all historical trace spans.
