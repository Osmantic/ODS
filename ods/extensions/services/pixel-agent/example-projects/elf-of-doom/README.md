# Elf of Doom

A small dungeon crawler that runs in your browser. You play an elf archer:
clear each arena of brutes, grab hearts and quivers, level up, and fight
through six realms to Mount Cinderfall.

## Play it

In Portal's sidebar, open Projects, then Playground, then elf-of-doom. The
game opens in Portal's Workspace panel. Click the game once so it gets your
keyboard.

- Arrow keys or WASD: move. You shoot the way you last moved.
- Space: shoot. Hold it to keep shooting.
- 1, 2, 3: choose a boon when you level up.
- Esc or P: pause. Enter: start or retry. M: mute.

Clicking outside the game pauses it. The game is plain HTML, CSS and
JavaScript and needs no internet connection, so you can also open
index.html in any web browser.

## Where it lives

This folder is Playground/elf-of-doom in your Portal workspace:

- Linux: ~/.openclaw/workspace-pixel/Playground/elf-of-doom
- Windows: the same path inside the Ubuntu (WSL) environment ODS runs in
- macOS: data/pixel-native/home/.openclaw/workspace-pixel/Playground/elf-of-doom
  inside your ODS install folder

## How it was made

Portal built this game in ODS, running Qwen3.8-Flash-Next, from
natural-language prompts. These files are exactly what it wrote.

See how it was made: https://odsspark.com

## It's yours

Play it, change it, or ask Portal to change it. Name it in your request, for
example "In elf-of-doom, make the arrows give 7". Portal changes this folder
only when you name it; later requests in that same chat can just say what to
change. A request for a new game always gets its own Playground folder.

ODS updates never overwrite or delete this folder. If you delete or rename
it, ODS does not add it again.
